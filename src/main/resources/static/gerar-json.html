Passo 1

Como gerar o arquivo JSON

Prepare o relatório no seu computador usando o AWS CLI. Nenhuma credencial é digitada no CloudSaver.

Preparar

Siga estas etapas

Passo 1 de 2
  1. Instale e configure o AWS CLIUse o guia oficial da AWS e execute aws configure no terminal.
  2. Abra uma pasta de trabalhoEscolha uma pasta no computador e abra o terminal nela. O arquivo será salvo nesse local.
  3. Execute o coletor abaixoNão existe um único comando AWS CLI para todos os serviços. O script junta os inventários mais comuns em resources.json; execute no PowerShell com o AWS CLI configurado. Cada comando termina com ; para funcionar mesmo se o terminal colar tudo em uma única linha.
    $inv = [ordered]@{ ec2Instances = @(aws ec2 describe-instances --query "Reservations[].Instances[].{InstanceId:InstanceId,InstanceType:InstanceType,State:State.Name}" --output json | ConvertFrom-Json); ebsVolumes = @(aws ec2 describe-volumes --query "Volumes[].{VolumeId:VolumeId,VolumeType:VolumeType,Size:Size,State:State}" --output json | ConvertFrom-Json); ebsSnapshots = @(aws ec2 describe-snapshots --owner-ids self --query "Snapshots[].{SnapshotId:SnapshotId,VolumeSize:VolumeSize,State:State}" --output json | ConvertFrom-Json); elasticIps = @(aws ec2 describe-addresses --query "Addresses[].{AllocationId:AllocationId,PublicIp:PublicIp,AssociationId:AssociationId}" --output json | ConvertFrom-Json); natGateways = @(aws ec2 describe-nat-gateways --filter Name=state,Values=available,pending --query "NatGateways[].{NatGatewayId:NatGatewayId,State:State}" --output json | ConvertFrom-Json); loadBalancers = @(aws elbv2 describe-load-balancers --query "LoadBalancers[].{LoadBalancerArn:LoadBalancerArn,Type:Type,State:State.Code}" --output json | ConvertFrom-Json); rdsInstances = @(aws rds describe-db-instances --query "DBInstances[].{DBInstanceIdentifier:DBInstanceIdentifier,DBInstanceClass:DBInstanceClass,Engine:Engine,DBInstanceStatus:DBInstanceStatus}" --output json | ConvertFrom-Json); s3Buckets = @(aws s3api list-buckets --query "Buckets[].{Name:Name,CreationDate:CreationDate}" --output json | ConvertFrom-Json) }; $inv | ConvertTo-Json -Depth 10 | Set-Content -Encoding utf8 resources.json
  4. Confirme se o arquivo foi criadoVerifique se recursos.json apareceu na pasta e possui conteúdo.
Segurança: suas credenciais ficam no AWS CLI local e não são solicitadas por esta interface.
