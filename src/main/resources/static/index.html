Saiba mais sobre o CloudSaver

O CloudSaver identifica recursos ociosos na AWS, calcula o desperdício financeiro e gera diagnósticos estratégicos via LLM.

Como utilizar ?

Para análise do CloudSaver, optamos por uma abordagem mais segura possível! Você não precisa fornecer nenhum acesso, senha ou nada sobre seu ambiente de infraestrutura, toda análise é feito através de um arquivo JSON gerado pela AWS CLI

Como gerar o arquivo JSON para análise?

No Aws CLI , execute o seguinte comando

aws ec2 describe-instances --query "Reservations[*].Instances[*].{InstanceId:InstanceId, InstanceType:InstanceType, State:State.Name, LaunchTime:LaunchTime, Tags:Tags}" > ec2_resources.json
